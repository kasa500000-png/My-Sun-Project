# UI·UX 시각 회귀 계약

`matrix.json`의 동일 화면·데이터·뷰포트로 before, after, diff를 생성한다.

- 실제 배포 캡처는 `deployed`
- 로컬 실행 캡처는 `local`
- 코드로 만든 fixture는 별도 표기하며 배포 화면으로 간주하지 않음
- 이메일, 사용자 ID, 개인 운동·식단 기록은 마스킹
- 동적 날짜·시간만 최소 범위로 마스킹
- 이미지가 생성됐다는 이유만으로 통과하지 않고 잘림·간격·CTA·키보드·탭 겹침을 사람이 검토

현재 실행 환경에서는 브라우저와 테스트 계정이 없어 PNG를 생성하지 않았다.
