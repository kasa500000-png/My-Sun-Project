## 적용한 보호 장치

- 모든 일반 인터랙티브 요소의 `focus-visible`을 3px로 통일
- 오류 입력의 `aria-invalid` 시 테두리와 링 표시
- 상태 배너에 색상 외 좌측 굵은 선과 모양 표시
- `prefers-contrast: more`에서 선·텍스트 대비 강화
- Windows forced colors에서 시스템 색상 사용
- 색상 토큰을 의미 기반 success/danger/warning/info로 분리

## 아직 필요한 실제 검증

- 키보드 탭 순서
- 모달 진입·포커스 트랩·복귀
- VoiceOver·TalkBack 읽기 순서
- 200%·400% 확대
- 색각 시뮬레이션과 차트 범례

- Windows 고대비 모드 실제 화면
