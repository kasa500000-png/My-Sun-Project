## 상태 정의

- `COMPLETE`: 해당 단계 산출물과 가능한 검증 완료
- `COMPLETE_WITH_BLOCKER`: 적용 가능한 작업은 완료했으나 외부 차단 사항 존재
- `CODE_VERIFIED`: 코드·정적 자동 검사 완료, 실화면 대기
- `VERIFIED`: 자동 검사와 실제 화면 검증 완료
- `BLOCKED`: 필수 권한·환경 부족으로 핵심 검증 불가
- `PLANNED`: 아직 수행 전
