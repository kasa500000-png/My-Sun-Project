## 강점

1. 차분한 아이보리·웜그레이 시각 방향과 운동 기록 제품의 정체성이 이미 형성돼 있다.
2. 모바일 터치 크기, Safe Area, 숫자 고정폭, 오프라인 배너, API 타임아웃 등 운영 앱 관점의 기반이 있다.
3. 운동·식단 데이터 의미와 계산 로직이 UI에서 완전히 분리되지는 않았지만 사용자 안내가 비교적 구체적이다.
4. 빈 상태와 오류 상태가 다수 구현돼 있어 개선 가능한 출발점이 좋다.

## 핵심 위험

1. `FitLogApp.tsx`가 화면·도메인 목록·계산·API·UI를 한 파일에 포함해 작은 디자인 변경도 회귀 범위가 넓다.
2. 모달은 Escape와 배경 닫기를 지원하지만 초기 포커스, 포커스 트랩, 닫힌 후 복귀가 보장되지 않는다.
3. 로그인 폼의 오류 의미와 필드 연결이 약해 인증 실패 시 복구 비용이 높다.
4. 식단 등록은 AI 대기·사진·영양 편집·저장이 한 모달에 겹쳐 작은 화면에서 인지 부하가 가장 크다.
5. 실화면 회귀 증거가 없어 현재 점수의 시각·반응형 신뢰도는 제한적이다.
