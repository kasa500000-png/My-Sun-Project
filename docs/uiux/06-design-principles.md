# 제품 디자인 원칙

## 브랜드 인상

마이썬 운동일지는 경쟁·과시보다 **꾸준한 기록과 회복 가능한 습관**을 돕는 도구다. 화면은 차분하고 친절하되, 사용자가 운동·영양 수치를 신뢰할 수 있을 만큼 정돈돼야 한다.

## 1. 오늘의 행동이 먼저다

- 홈 첫 화면에는 주간 목표, 오늘의 상태, 가장 중요한 기록 CTA를 우선한다.
- 과거 기록·상세 분석은 핵심 행동을 가리지 않는 2차 계층으로 둔다.
- 한 화면에 동일한 무게의 CTA를 여러 개 만들지 않는다.

## 2. 기록은 빠르고 복구 가능해야 한다

- 모바일에서 운동 하나를 기록할 때 불필요한 화면 전환을 줄인다.
- 입력 오류는 해당 필드 가까이에서 이유와 해결 방법을 설명한다.
- 저장·삭제·닫기 결과를 즉시 알리고, 미저장 입력 손실 가능성을 숨기지 않는다.

## 3. 숫자는 맥락과 함께 보여준다

- 운동 부하, 자극 비율, 칼로리, 영양값에는 기간·단위·계산 또는 추정 여부를 함께 표시한다.
- AI 식단 분석값은 사용자 확정값과 시각·문구로 구분한다.
- 데이터가 적을 때 강한 결론이나 과도한 추천을 피한다.

## 4. 카드보다 정보 그룹이 우선이다

- 독립적인 행동·상태·데이터 묶음에만 카드를 사용한다.
- 단순 제목과 설명을 모두 카드로 감싸지 않는다.
- 중첩 카드보다 구분선, 여백, 배경 단계로 관계를 표현한다.

## 5. 의미 기반 색상을 사용한다

- 잉크색: 기본 핵심 행동과 텍스트
- 녹색: 저장 완료·선택·안정 상태
- 빨강: 오류·삭제·위험 행동
- 황색: 오프라인·주의·확인 필요
- 회색: 보조 정보·비활성 상태

색상만으로 성공·오류·선택을 전달하지 않고 문구와 아이콘을 함께 제공한다.

## 6. 조용한 시각 밀도

- 화면 제목은 과도하게 크지 않되 섹션 제목과 명확히 구분한다.
- 작은 회색 텍스트를 남용하지 않고 최소 본문 대비를 유지한다.
- 숫자는 tabular-nums와 명확한 단위를 사용한다.
- 그림자는 계층을 설명할 때만 약하게 사용한다.

## 7. 모바일은 축소판이 아니다

- 360px에서 터치 대상, 키보드, 하단 탭, Safe Area가 우선이다.
- 태블릿과 데스크톱은 콘텐츠 폭을 제한하고 필요한 경우 2열로 재배치한다.
- 긴 한국어, 큰 글자, 큰 수치에서도 CTA와 입력이 잘리지 않아야 한다.

## 8. 모션은 상태 변화만 설명한다

- 눌림, 저장, 화면 전환의 맥락을 알려주는 짧은 모션만 사용한다.
- 반복·장식 애니메이션을 피한다.
- `prefers-reduced-motion`에서 기능과 정보 전달이 동일하게 유지돼야 한다.

## 9. 기존 사용자 기억을 보존한다

- 핵심 탭 명칭과 운동·식단 흐름을 이유 없이 바꾸지 않는다.
- 아이보리·웜그레이·차분한 녹색의 브랜드 방향을 유지한다.
- 기능을 숨기거나 제거해 화면을 단순하게 보이게 만들지 않는다.

## 10. 완료보다 검증을 우선한다

- 코드가 작성됐다는 이유만으로 실화면 검증 완료로 표시하지 않는다.
- 배포·로컬·fixture 증거를 구분한다.
- 검증하지 못한 기기·상태는 최종 보고서에 명시한다.

## 시각 규격 방향

| 항목 | 원칙 |
|---|---|
| 화면 배경 | 아이보리 캔버스, 섹션 배경은 웜그레이 |
| 카드 반경 | 14~18px, 바텀시트 22px |
| 버튼 | 핵심 48px, 보조 최소 44px, pill 형태 제한적 사용 |
| 그림자 | 저대비 1단계, 모달과 고정 영역만 2단계 |
| 구분선 | 1px 웜그레이, 카드 중첩 대신 활용 |
| 화면 여백 | 모바일 16px, 태블릿·데스크톱 24~32px |
| 최대 본문 폭 | 읽기 화면 720~960px, 대시보드 1200~1440px |
| 애니메이션 | 120~180ms, ease-out 중심 |
