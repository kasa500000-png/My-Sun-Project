# 운동 탐색·목록·루틴 개선

## 현재 탐색 모델

1. 날짜·운동 시간
2. 상단 고정 메모·저장 상태
3. 운동 검색
4. 루틴 탭
5. 부위 하위 탭
6. 결과 수
7. 즐겨찾기 우선 정렬된 운동 목록
8. 선택 운동 요약

검색어 또는 루틴을 바꾸면 선택 입력 모달이 닫히고, 루틴 변경 시 검색과 하위 탭이 초기화된다.

## 적용한 개선

- 루틴·하위 탭을 scroll snap으로 정돈해 작은 화면에서 항목 시작점이 안정적으로 보이게 함
- 운동 행 기본·포커스·선택·hover 상태의 테두리와 그림자를 의미 기반으로 통일
- 선택된 운동에 녹색 점과 기존 좌측 선·문구를 함께 사용해 색상 하나에 의존하지 않음
- 389px 이하에서 상단 고정 상태와 메모·저장 CTA를 2행으로 전환
- 작은 화면 운동 행 높이·간격을 늘려 긴 이름과 상태 배지를 보호
- hover는 정밀 포인터에서만 사용

## 보존한 동작

- 즐겨찾기 우선 정렬
- 한국어 검색 정규화
- 루틴·부위 필터
- 선택한 운동의 세트·무게·횟수
- 저장 완료 후 기록과 자극 분석

## 추가 코드 변경 후보

대형 `FitLogApp.tsx`의 회귀 위험 때문에 다음은 이번 CSS 단계에서 직접 바꾸지 않았다.

- 검색 입력의 `type="search"`와 결과 live region
- 선택 수를 독립 status로 읽기
- 모달 초기 포커스·포커스 트랩
- 빈 검색 결과에서 루틴 초기화 CTA

해당 항목은 테스트 계정과 브라우저 실행 후 작은 기능 단위 PR로 분리하는 것이 안전하다.
