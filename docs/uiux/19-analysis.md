# 운동 분석·차트·리포트 개선

## 데이터 의미 보존

다음 계산과 문구 생성 로직은 변경하지 않았다.

- 기간별 운동 세션 선택
- 근육별 자극 점수
- 부위 밸런스
- 누적 부하
- 상위 자극 비율
- 기록 수에 따른 신뢰 안내
- 추천 루틴과 추천 이유

## 적용한 개선

- 분석 화면 제목을 공통 fluid 타이포그래피와 맞춰 작은 화면 줄바꿈을 안정화
- 지표 기준 `details`의 44px 터치 영역과 열림 상태를 명확히 표시
- 도넛 차트에 경계와 내부 여백을 추가해 배경과 분리
- 범례 색상 점에 외곽선을 추가해 유사한 밝기의 색도 구분 가능하게 함
- 숫자 지표에 tabular 숫자 정렬 적용
- 고대비·forced-colors에서 차트를 시스템 색상과 이중 경계로 대체

## 데이터 신뢰 기준

- 기간명, 기록 횟수, 누적 부하 단위를 함께 표시한다.
- 기록 1회인 경우 현재 구현의 신뢰도 안내를 유지한다.
- 색상 차트는 시각 보조이며, 범례의 부위명과 점수가 실제 의미 전달의 기준이다.

## 남은 접근성 작업

- 도넛 차트의 스크린리더용 요약 표
- 막대 순위의 `aria-label` 또는 구조화된 목록 확인
- 200% 확대에서 차트와 범례 배치
- 색각 시뮬레이션

실제 DOM과 보조기술을 확인하기 전 차트 접근성을 완료로 표시하지 않는다.
