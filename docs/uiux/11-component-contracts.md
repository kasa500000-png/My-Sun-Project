# 공통 UI 컴포넌트 계약

## 추가 컴포넌트

### `AppStatePage`

오류, 404, 오프라인처럼 전체 화면을 점유하는 상태에 사용한다.

필수 정보:

- 상태 종류를 설명하는 eyebrow
- 사용자가 이해할 수 있는 제목
- 데이터 안전 여부와 원인을 포함한 설명
- 한 개의 명확한 기본 행동
- 선택적 보조 행동과 기술 세부 정보

### `StatusMessage`

inline 성공·오류·주의·정보 메시지에 사용한다.

- danger는 `role="alert"`, assertive live region
- 나머지는 `role="status"`, polite live region
- `aria-atomic="true"`로 전체 문장을 읽음
- 색상 외 선·모양 상태 표시 포함

### `FieldMessage`

입력 도움말과 오류를 필드 가까이에 연결한다.

- `id` 필수
- 입력은 `aria-describedby`로 연결
- 오류 시 입력에 `aria-invalid="true"`

## 도입 순서

1. 오류·404·오프라인 화면
2. 로그인·회원가입 상태
3. 운동·식단 입력 오류
4. 앱 전역 inline 오류와 저장 피드백

## 회귀 방지

- 도메인 계산이나 API 계약을 포함하지 않는다.
- 컴포넌트는 서버·클라이언트 화면 모두에서 사용할 수 있도록 브라우저 API에 의존하지 않는다.
- 기존 화면을 한 번에 모두 치환하지 않고 공통 상태부터 적용한다.
