# 전체 화면 및 상태 인벤토리

## 인벤토리 기준

- 인증 후 핵심 화면은 `/` 내부에서 `?tab=` 쿼리와 React 상태로 전환된다.
- 저장·삭제가 필요한 동작은 테스트 계정 또는 로컬 데이터에서만 검증한다.
- `검증`의 `코드`는 소스 분석 완료, `실화면`은 실제 브라우저 검증 필요를 뜻한다.

## 존재하지 않아 임의 생성하지 않는 화면

- 별도 온보딩 화면
- 푸시 알림 센터와 알림 설정
- 구독·결제 화면
- 다크 모드
- 계정 탈퇴 화면
- 별도 비밀번호 재설정 화면
- 네이티브 전용 React Native·Capacitor 화면

해당 항목은 현재 제품 범위 밖으로 기록하며, 30단계 수행을 위해 가짜 기능을 추가하지 않는다.
