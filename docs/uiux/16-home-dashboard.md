# 홈 대시보드 개선

## 정보 우선순위

1. 이번 주 목표와 남은 횟수
2. 운동 기록 CTA
3. 선택 기간 운동 요약
4. 오늘 추천 루틴
5. 최근 운동과 분석 미리보기

현재 홈은 이 순서를 대체로 따르고 있으므로 구조를 전면 재작성하지 않고 시각 계층과 모바일 첫 화면 도달 속도를 개선했다.

## 적용한 개선

- 모바일 히어로 높이를 26svh 고정 성격에서 `clamp(14rem, 28svh, 22rem)`으로 제한
- 389px 이하에서는 13rem으로 축소해 목표 카드와 CTA가 더 빨리 나타나도록 함
- 데스크톱 히어로는 20~26rem 범위로 제한
- 히어로 오버레이 대비와 이미지 초점을 정돈
- 주간 목표 카드에 의미 기반 녹색 상단 경계와 저대비 배경 강조 추가
- 카드 hover는 마우스·정밀 포인터 환경에서만 적용

## 보존한 데이터

- 주간 목표 계산
- 완료 비율
- 남은 횟수
- 추천 루틴과 추천 이유
- 기간별 운동 요약과 밸런스
- 최근 기록과 분석 미리보기

## 후속 실화면 확인

- 히어로 이미지의 인물·핵심 피사체가 360/390/412px에서 잘리지 않는지
- 목표 카드 CTA가 첫 화면 또는 한 번의 짧은 스크롤 안에 보이는지
- 기록 없음·목표 완료·주간 fallback 상태
- 768px에서 히어로와 카드 사이 여백
