# 설정·프로필·계정 관리

## 현재 설정 구조

- 로그인 계정
- 개인 운동 정보: 성별, 나이, 키, 몸무게, 활동량
- 주간 운동 목표
- 개인 루틴 즐겨찾기
- 로그아웃

구독·결제·계정 탈퇴·테마 설정은 현재 제품에 존재하지 않아 임의로 추가하지 않았다.

## 발견한 실수 위험

내 정보 모달의 닫기 버튼과 Escape는 로컬 값을 원래 설정으로 복원하지만, 배경 클릭은 단순히 모달만 닫아 로컬 미저장 값이 화면에 남을 수 있었다. 서버 저장은 되지 않았는데 카드 미리보기는 바뀐 것처럼 보일 수 있어 데이터 신뢰를 해칠 수 있다.

## 적용한 개선

- 설정 카드의 포커스·hover·최소 높이와 시각 계층 정돈
- 로그인 계정 카드를 다른 설정 카드와 구분
- 내 정보 설정 모달의 배경 클릭 닫기를 CSS 상호작용에서 차단
- 사용자는 명시적 닫기 또는 Escape를 사용하며, 기존 `closeModal()`이 원래 설정으로 복원
- 저장 버튼을 긴 모달 하단에 고정해 키보드·스크롤 후에도 접근 가능
- 즐겨찾기 선택 상태의 경계를 보강
- 모션 감소 설정에서 카드 이동 제거

## 보존한 데이터

- 설정 저장 API
- 주간 목표 범위
- 신체 정보 정제
- 활동량 값
- 즐겨찾기 운동 목록
- 로그아웃 동작

## 남은 제품 범위

- 변경 감지 문구와 ‘저장하지 않고 나가기’ 확인창
- 계정 탈퇴
- 개인정보처리방침·이용약관·고객지원 링크
- 앱 버전 표시

현재 저장소에 관련 기능과 정책 문서가 없어 이번 UI 브랜치에서 만들지 않았다.
