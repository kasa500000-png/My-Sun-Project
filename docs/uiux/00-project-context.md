# UI·UX 개선 프로젝트 컨텍스트

## 프로젝트

- 공식 앱 이름: 마이썬 운동일지
- 저장소: `kasa500000-png/My-Sun-Project`
- 기준 브랜치: `main`
- 작업 브랜치: `codex/uiux-30-stage-improvement`
- 기준 커밋: `3e2cc66312b73ef15a026a7d42b1aebaeba23298`
- 배포 메타데이터 기준 URL: `https://my-sun-project.vercel.app`

## 목표

배포된 모바일 우선 운동·식단 기록 앱의 시각적 완성도, 정보 구조, 입력 편의성, 접근성, 반응형 안정성과 실패 복구 경험을 개선한다. 단순 감사에 그치지 않고 안전한 공통 기반부터 실제 코드를 수정한다.

## 프롬프트 치환 규칙

초기 실행 프롬프트는 SwingLog 금융 앱을 예시로 작성됐지만 저장소 분석 결과 실제 제품은 운동·식단 기록 앱이다. 따라서 금융 전용 단계는 다음과 같이 제품의 동등한 핵심 흐름으로 치환한다.

| 원래 예시 | 실제 적용 대상 |
|---|---|
| 시장 브리핑·뉴스 | 홈 운동 요약·추천 루틴 |
| 관심 종목 | 즐겨찾기 운동·검색·필터 |
| 종목 분석 리포트 | 근육 자극·부위 밸런스 분석 |
| 매매 계획·위험 관리 | 주간 운동 목표·식단 목표·운동 부하 |
| 매매일지 | 운동 일지·식단 기록 |
| 투자 통계 | 운동량·부위별 자극·영양 통계 |
| 알림·일정 | PWA 상태·오프라인·기록 일정 |

## 보존 대상

- 운동 세트와 볼륨 계산
- 부위별 자극 비율과 분석 로직
- 식단 칼로리·탄수화물·단백질·지방 계산
- Supabase 인증, RLS 및 API 계약
- 사용자 설정과 기존 기록
- PWA manifest, service worker, 설치 동작
- 기존 아이보리·웜그레이 중심 브랜드

## 현재 실행 제약

연결된 Vercel 도구에서 과거 `my-sun-project` 프로젝트가 현재 조회되지 않는다. 컨테이너 환경은 외부 DNS가 차단되어 GitHub/Vercel 원격 앱을 직접 열 수 없다. 따라서 이번 브랜치에서는 저장소 기반 감사, 정적 계약 테스트, 코드 수준 개선과 GitHub/Vercel 상태 확인을 우선하며, 배포 실화면·인증 후 운영 데이터 화면은 최종 품질 게이트에서 미검증 항목으로 분리한다.
