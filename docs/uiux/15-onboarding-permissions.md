# 첫 실행·온보딩·권한 요청 범위

## 저장소 확인 결과

현재 앱에는 다음 기능이 존재하지 않는다.

- 별도 다단계 온보딩
- 푸시 알림 권한 요청
- 생체 인증
- 추적 권한
- 카메라 직접 촬영 권한
- 네이티브 위치·연락처 권한

식단 이미지는 웹 파일 선택기를 통해 사용자가 명시적으로 선택하며, 별도 네이티브 권한 화면을 만들 필요가 없다.

## 적용 결정

가짜 온보딩이나 불필요한 권한 요청을 추가하지 않는다. 첫 진입의 제품 가치 설명은 Stage 14 로그인 히어로에 짧게 통합했다.

## 첫 실행 품질 기준

- 로그인 전에 앱이 운동·식단 기록 도구임을 알 수 있다.
- 회원가입을 건너뛰고 핵심 앱을 사용하는 익명 모드는 기존 제품 정책에 없으므로 만들지 않는다.
- 회원가입 후 빈 홈에서는 주간 목표 또는 첫 운동 기록으로 이어지는 CTA가 필요하다.
- 향후 알림 기능이 추가되면 기능 사용 직전에 권한 이유를 설명하고, 거부해도 핵심 기록 기능은 유지한다.

## 후속 제품 제안 — 이번 변경에 포함하지 않음

1. 첫 로그인 후 한 번만 표시되는 2단계 설정: 주간 운동 목표, 즐겨찾기 운동
2. 식단 이미지 선택 직전 개인정보·AI 추정 안내
3. PWA 설치 유도는 반복 팝업 대신 사용자가 필요성을 느낀 시점에 제공

이 제안들은 데이터 모델과 제품 범위 검토가 필요하므로 현재 UI 개선 브랜치에서 구현하지 않는다.
