# 내비게이션과 정보 구조

## 현재 구조

- 공개 인증: `/login`
- 인증 후 앱: `/`
- 핵심 영역: 홈, 운동 기록, 일지, 분석, 식단, 내 정보
- 모바일 하단 메뉴: 홈·일지·분석·식단·내 정보
- 운동 기록: 상단의 독립 핵심 CTA

## 적용한 개선

- 전역 레이아웃에 `본문으로 건너뛰기` 링크 추가
- skip target을 포커스 가능한 `#app-content`로 고정
- 하단 메뉴 활성 항목에 색상 외 2px 지시선 제공
- 고정 헤더 아래 포커스 scroll margin은 Stage 10 전역 규칙을 사용

## 보존한 결정

운동 기록은 하단 6번째 탭으로 추가하지 않았다. 기록은 앱 전체에서 가장 중요한 생성 행동이며, 기존 상단 CTA에 익숙한 사용자의 기억을 보존한다.

## 후속 검증

- 브라우저 뒤로 가기와 내부 탭 상태
- 모달을 딥링크로 열었을 때 복귀 위치
- 하단 탭 전환 후 스크롤 위치 유지
- Android 시스템 뒤로 가기
- 서비스워커 알림 또는 외부 링크 진입

해당 동작을 실화면에서 검증하기 전 딥링크 완료로 판정하지 않는다.
