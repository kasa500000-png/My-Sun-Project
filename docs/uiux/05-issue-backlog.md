## 처리 순서

1. 인증·Skip Link·상태 화면·반응형 기반
2. 입력·오류·모달 접근성
3. 운동·식단 핵심 여정
4. 분석 신뢰·설정 실수 방지
5. 성능·모션·시각 폴리시

## 완료 정의

- 코드 수정만으로 `RESOLVED` 처리하지 않는다.
- 자동 검사 완료 시 `CODE_VERIFIED`, 실제 브라우저 확인까지 완료 시 `VERIFIED`로 승격한다.
- 실행 환경 차단은 `BLOCKED`로 유지하며 성공으로 계산하지 않는다.
