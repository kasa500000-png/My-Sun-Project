# 피드백·모션·마이크로인터랙션

## 원칙

- 모션은 상태 변화와 눌림 결과만 설명한다.
- 기본 전환은 120ms, 계층 변화는 180ms를 사용한다.
- 반복·장식 애니메이션을 만들지 않는다.
- `prefers-reduced-motion`에서는 같은 기능을 모션 없이 제공한다.
- hover는 정밀 포인터에서만 적용한다.

## 적용한 개선

- 주요 버튼, 아이콘 버튼, 탭, 운동 행, 비밀번호 토글의 전환 시간을 통일
- 눌림 상태를 0.985 scale로 미세하게 표현
- busy 상태에서 progress cursor와 콘텐츠 투명도 제공
- 전역 토스트를 긴 문장에도 적합한 카드 반경·줄 높이·최소 높이로 변경
- 하단 탭과 Safe Area 위에 유지되는 기존 위치 계약 보존
- 토스트 진입 모션을 180ms 한 번만 실행
- 389px 이하에서 토스트 폭과 글자 크기를 안정화
- forced-colors에서 시스템 표면과 경계 사용

## 보존한 동작

- 토스트 표시 시간과 상태 로직
- 저장 성공·오류 문구
- 하단 탭 위치
- API 요청과 데이터 처리

## 남은 실제 검증

- 긴 한국어 토스트와 200% 확대
- 하단 탭·키보드·토스트 동시 표시
- 터치 장치의 active 상태
- 네이티브 햅틱은 현재 PWA에 없어 적용하지 않음
