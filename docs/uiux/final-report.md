## 8. 화면별 핵심 개선

### 인증

이메일 목적, 자동완성, 비밀번호 표시, 탭 시맨틱, 필드별 오류와 전역 상태를 분리했다. 비밀번호 불일치 오류와 표시·숨기기 동작을 실제 Chromium으로 검증했다.

### 홈

히어로 높이를 제한하고 주간 목표와 운동 기록 CTA를 우선 배치했다. 모바일과 데스크톱에서 카드 밀도와 최대 폭을 정돈했다.

### 운동 기록

검색, 루틴·부위 탭, 운동 선택 상태, sticky action과 긴 목록을 개선했다. 기준 화면의 360px·390px 가로 넘침을 제거했다.

### 일지·달력

날짜 셀과 이동 버튼을 44px 기준으로 정비하고 기록 상태·포커스·숫자 정렬을 강화했다.

### 분석

차트와 범례의 경계, 지표 기준 펼침 상태, 고대비 표현을 개선했다. 가로 스크롤 근육 순위를 키보드 포커스로 진입할 수 있게 했다.

### 식단

영양 수치와 목표값을 작은 화면에서도 완전히 표시하고, 달력·목표·기간 요약의 터치 크기와 정보 계층을 정돈했다.

### 내 정보

설정 카드의 상태와 저장 CTA를 개선하고, 배경 클릭으로 미저장 값이 혼동되는 흐름을 차단했다.

### 시스템 상태

로딩, 오류, 404, 오프라인을 공통 구조로 통합하고 데이터 영향·재시도·홈 이동을 일관되게 제공했다.

## 16. 롤백 방법

현재 변경은 Draft PR의 별도 브랜치다.

1. 병합 전에는 PR을 닫고 브랜치를 폐기한다.
2. 병합 후에는 UI·UX PR 전체를 revert한다.
3. Vercel에서 직전 정상 프로덕션 배포로 rollback한다.
4. service worker를 직전 캐시 버전으로 재배포한다.
5. DB·API 마이그레이션이 없으므로 데이터 롤백은 필요하지 않다.
