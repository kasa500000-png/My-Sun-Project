## 8. 화면별 핵심 개선

### 인증

이메일 목적, 자동완성, 비밀번호 표시, 탭 시맨틱, 필드 오류와 전역 오류 분리, 제출 중 상태를 개선했다.

### 홈

모바일 히어로 높이를 제한하고 주간 목표와 기록 CTA를 더 빠르게 확인하도록 카드 계층을 조정했다.

### 운동 기록

긴 탭의 scroll snap, 선택 운동 상태, 작은 화면 sticky actions, 운동 행 포커스·터치·hover를 정돈했다.

### 일지·통계

달력 날짜·기록 상태 경계, 숫자 정렬, 식단 영양 요약과 표 계약을 보강했다.

### 분석

지표 기준 펼침 상태, 도넛·범례 경계, 고대비 대체 표현과 수치 가독성을 개선했다.

### 식단·목표

작은 화면 다열 입력을 완화하고 자동 계산 근거, 숫자 정렬, 모달 스크롤·footer를 정돈했다.

### 내 정보

우발적 배경 닫기를 막아 미저장 값 혼동을 줄이고 긴 모달의 저장 CTA를 고정했다.

### 오류·오프라인

데이터 영향, 중복 저장 주의, 복구 행동, 오류 식별자와 실시간 연결 상태를 일관되게 제공한다.

## 9. 접근성 개선

- 브라우저 확대 허용
- 전역 skip link
- 3px focus-visible
- 인증 tablist/tab/tabpanel 연결
- 입력 `aria-invalid`·`aria-describedby`
- alert/status live region
- 상태 색상 외 선·모양
- prefers-contrast, forced-colors, reduced-motion
- 모바일 입력 16px와 Safe Area

모달 포커스 트랩, 스크린리더, 200%·400% 확대, axe는 실제 환경 미검증이다.

## 10. 성능 개선

- Pretendard CSS preload
- 긴 카드·섹션의 `content-visibility`와 intrinsic size
- 작은 화면·투명도 감소 선호에서 backdrop blur 제거
- 데이터 절약 선호에서 대형 배경 이미지 생략
- 인증 후 HTML 서비스 워커 캐시 금지
- 정적 성능 회귀 테스트

LCP, CLS, INP, 번들 크기와 프레임은 측정하지 못했다. 가장 큰 구조적 후보인 `FitLogApp.tsx` 분리는 별도 측정·E2E PR로 남긴다.

## 16. 롤백 방법

현재 변경은 별도 브랜치이며 `main`에 병합하지 않았다. 가장 안전한 롤백은 Draft PR을 닫고 브랜치를 폐기하는 것이다.

병합 후 문제가 생기면 다음 순서로 처리한다.

1. 전체 UI·UX PR을 GitHub에서 revert
2. Vercel의 직전 정상 프로덕션 배포로 rollback
3. 서비스 워커가 직전 버전으로 활성화되도록 새 배포
4. 브라우저에서 이전·신규 `mysun-fit-log-*` 캐시 정리 확인
5. DB·API 변경은 없으므로 데이터 롤백은 불필요
