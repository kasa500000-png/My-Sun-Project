# 통계·성과·복기 시각화

## 실제 제품의 통계 범위

- 일·주·월·년 운동 횟수
- 운동 시간과 총 세트
- 운동한 날짜
- 부위별 자극 점수와 비율
- 식단 칼로리와 탄수화물·단백질·지방
- 기간별 식단 상세

수익률·승률처럼 금융 앱 전용 지표는 존재하지 않으므로 새로 만들지 않았다.

## 적용한 개선

- 핵심 수치에 tabular 숫자 정렬을 확대 적용
- 운동 달력 날짜 버튼의 최소 크기·포커스·기록 상태 경계를 보강
- 달력 범례 점에 경계를 추가해 밝은 배경에서 식별성 향상
- 식단 3분할 영양 요약의 최소 폭·숫자 정렬을 보호
- 향후 표 데이터에 사용할 공통 표 간격·구분선 계약 추가
- 작은 화면에서 달력 셀과 영양 요약 간격을 조정

## 해석 원칙

- 기간과 기록 수를 지표 가까이에 둔다.
- 기록이 적을 때 빈 상태 또는 신뢰 안내를 제공한다.
- 차트·색상은 보조이며, 텍스트 값과 단위가 기준이다.
- 운동 부하 ‘점’은 실제 중량 단위가 아닌 앱 계산값임을 유지한다.

## 남은 검증

- 360px 달력 셀의 실제 44px 터치 크기
- VoiceOver·TalkBack에서 날짜와 기록 수 읽기
- 매우 큰 운동·칼로리 수치
- 200% 확대 시 식단 영양 요약
