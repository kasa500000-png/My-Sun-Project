# 즐겨찾기·검색·정렬 경험

## 현재 동작

- 운동 기록과 내 정보의 개인 루틴 모달에서 운동 이름 검색을 제공한다.
- 현재 루틴과 하위 부위 조건 안에서 검색한다.
- 선택된 즐겨찾기는 목록 상단으로 정렬된다.
- 운동 행에는 ‘자주 하는 운동’ 배지가 표시된다.

## 적용한 개선

- 운동 검색 입력에 일관된 돋보기 표시를 추가해 입력 목적을 더 빠르게 인식하도록 함
- 포커스 시 아이콘 색을 포커스 색상으로 변경
- 루틴·하위 탭의 선택 상태에 색상 외 하단 지시선 추가
- 긴 ‘자주 하는 운동’ 배지가 운동명을 밀지 않도록 최대 폭과 말줄임 적용
- 작은 화면과 forced-colors에서 안전한 fallback 제공

## 보존한 동작

- 즐겨찾기 우선 정렬
- 중복 선택 방지
- 현재 루틴·하위 탭 범위
- 한국어 정규화 검색
- 저장 전 로컬 선택 상태

## 후속 개선 후보

- 검색어 지우기 버튼
- 결과 수를 `aria-live="polite"`로 제공
- 검색 결과 없음에서 전체 루틴 보기 CTA
- 저장하지 않고 닫을 때 변경 사항 확인

위 항목은 대형 핵심 컴포넌트의 이벤트·상태 변경을 수반하므로 실제 브라우저 회귀 환경에서 분리 적용한다.
