# 시작·로딩·스켈레톤 경험

## 변경 전

- 둥근 직사각형 4개가 화면 구조와 약하게 대응했다.
- 실제 보이는 스켈레톤과 스크린리더용 상태 문구가 같은 status 영역에 섞여 있었다.
- 2개 카드가 360px에서도 항상 2열이었다.

## 변경 후

- 헤더, 홈 히어로, 핵심 지표 카드의 실제 정보 계층을 반영했다.
- 시각 스켈레톤은 `aria-hidden`, 상태 문구만 live region으로 제공한다.
- `aria-busy="true"`로 화면 준비 중임을 명시한다.
- 389px 이하에서는 지표 카드가 1열로 전환된다.
- skeleton과 spinner는 모션 감소 설정에서 정지한다.
- 고정 높이를 남용하지 않고 `clamp`와 svh를 사용해 레이아웃 이동을 줄인다.

## 후속 측정

- 첫 콘텐츠 표시 시간
- 세션 복원 완료까지 걸린 시간
- 로딩 완료 전후 레이아웃 이동
- 느린 3G에서 중복 로딩 문구
- 캐시 데이터 우선 표시 가능성
