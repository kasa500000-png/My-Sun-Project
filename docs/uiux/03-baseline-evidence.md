## 정적 기준 증거

### 공통 디자인

- 아이보리 캔버스, 웜그레이 표면, 짙은 잉크색 텍스트, 녹색 성공 상태를 사용한다.
- 공통 토큰이 있으나 `FitLogApp.tsx`의 `UI` 객체와 화면별 Tailwind 값이 중복된다.
- 44px 터치 기준과 `focus-visible`, `prefers-reduced-motion` 처리가 이미 일부 구현돼 있다.

### 로그인

- 모바일에서 상단 히어로와 하단 폼, 데스크톱에서 좌우 2열 구조다.
- 로그인·회원가입 탭, 이메일·비밀번호, 회원가입 비밀번호 확인이 있다.
- 비밀번호 보기, 필드별 오류 연결, 오류·안내 상태 구분이 없다.

### 핵심 앱

- 상단 고정 헤더와 모바일 하단 5개 탭을 사용한다.
- 운동 기록은 별도 하단 탭이 아니라 상단 `기록` CTA로 진입한다.
- 홈의 대형 이미지 히어로는 브랜드 인상을 주지만 작은 화면에서 핵심 정보 도달을 늦출 수 있다.
- 식단 화면은 캘린더, 기간 요약, 식단 등록, AI 분석, 목표 설정이 밀집돼 있다.

## 스크린샷 정책

실제 브라우저로 캡처하지 못한 화면을 ‘실화면’이라고 표기하지 않는다. `artifacts/uiux/before`와 `after`에는 다음 중 하나의 출처 라벨을 반드시 남긴다.

- `deployed`: 배포 URL 실제 브라우저 캡처
- `local`: 로컬 Next.js 실행 캡처
- `fixture`: 코드 기반 시각 fixture이며 실제 런타임 검증이 아님

동적 개인 정보는 마스킹하고 비밀번호·토큰·이메일 원문을 남기지 않는다.

## 후속 캡처 매트릭스

- 모바일: 360×800, 390×844, 412×915
- 태블릿: 768×1024
- 데스크톱: 1280×800, 1440×900
- 상태: 기본, 빈 상태, 오류, 오프라인, 키보드 열림, 긴 텍스트

## 차단 해제 조건

- Vercel `my-sun-project` 프로젝트를 현재 연결 권한에 다시 노출하거나,
- 배포 Preview URL을 GitHub commit status에서 확인하고 브라우저 접근이 가능한 환경에서 실행하거나,
- Supabase 테스트 환경변수와 의존성이 준비된 로컬 실행 환경을 제공한다.
