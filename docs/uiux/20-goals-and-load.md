# 목표·운동 부하·식단 목표 표현

## 사용자 구분이 필요한 값

- 사용자가 설정한 주간 운동 목표
- 기록된 실제 운동 횟수
- 앱이 계산한 운동 누적 부하
- 프로필을 기준으로 자동 계산한 식단 목표
- 사용자가 직접 수정한 칼로리·단백질 목표

## 적용한 개선

- 홈 목표 진행 막대의 트랙과 완료 구간을 시각적으로 분리
- 진행 변화 모션을 짧고 차분하게 적용하고 모션 감소 설정에서는 제거
- 식단 목표의 칼로리·단백질 입력을 tabular 숫자로 정렬
- 389px 이하에서 두 개 목표 입력과 자동 계산·저장 버튼을 1열로 전환
- 자동 계산 근거 안내를 정보 색상과 좌측 경계로 구분
- 자동 계산 미리보기 카드를 일반 안내와 분리
- forced-colors에서 진행 구간과 계산 안내를 시스템 색상으로 대체

## 변경하지 않은 계산

- 주간 목표 범위 1~14회
- 주간 완료 비율
- 활동량·신체 정보 기반 목표 계산
- 칼로리·단백질·탄수화물·지방 범위
- 사용자가 수정한 값의 저장 계약

## 남은 코드 개선

현재 목표 입력은 자동 계산값을 불러온 뒤 사용자가 수정했는지를 별도 상태로 표시하지 않는다. 이 구분은 데이터 모델과 저장 시점 검증이 필요하므로 실제 런타임 테스트와 함께 후속 변경으로 남긴다.
