# 운동·식단 기록 폼 UX

## 핵심 폼 범위

- 운동 날짜와 시간
- 운동 검색·선택
- 세트 수, 체중, 중량, 반복 또는 시간
- 운동 메모
- 식단 날짜·식사 구간·사진
- 음식명·분량·칼로리·탄수화물·단백질·지방
- 식단 목표

## 적용한 개선

- 모달 입력의 최소 높이와 숫자 정렬을 공통화
- 텍스트 영역의 읽기 리듬과 키보드 스크롤 여백을 확보
- 모달 스크롤 영역에 overscroll containment 적용
- 운동 입력·메모 footer를 하단에 안정적으로 유지하고 Safe Area 반영
- 389px 이하에서 운동 2열 입력과 식단 4열 입력을 1열로 전환
- 3열 입력은 2열로 완화하고 RPE 5열은 최소 폭·간격을 보호
- disabled·busy 상태를 시각적으로 구분
- 브라우저 유효성 오류와 `aria-invalid` 상태의 경계를 통일

## 데이터 의미 보존

- 운동별 기록 방식과 볼륨 계산
- 편측 운동 합산 규칙
- 체중형 운동의 체중 필수 조건
- RPE와 강도 선택
- 식단 AI 분석·직접 입력·영양 계산
- 저장 가능 조건과 API 요청

## 남은 기능 개선

- 운동 입력의 필드별 오류 문구
- 미저장 메모·설정 이탈 확인
- 식단 등록의 명시적 단계 표시
- 키보드가 열린 실제 iOS·Android 화면

이 항목들은 상태 로직 변경과 실제 키보드 회귀 테스트가 필요해 미검증 상태로 남긴다.
